# دليل تحديث المشروع واستيراد التحديثات من GitHub إلى السيرفر (Update Guide)

هذا الدليل يوضح الخطوات البسيطة والواضحة لتحديث موقعك الإلكتروني بعد قيامك بأي تعديلات برمجية على جهازك المحلي، ورفعها إلى GitHub، ثم تطبيقها وبنائها على سيرفر Beget VPS بنجاح 100%.

---

## الخطوة 1: حفظ ورفع التعديلات من جهازك المحلي إلى GitHub
قبل أي شيء، بعد انتهائك من تعديل الكود على جهازك الكمبيوتر، افتح الطرفية (Terminal أو Git Bash) داخل مجلد المشروع المحلي وشغل الأوامر التالية:

```bash
# 1. إضافة جميع الملفات المعدلة
git add .

# 2. حفظ التعديلات مع كتابة وصف مختصر لها
git commit -m "update: وصف التعديلات التي قمت بها"

# 3. رفع التعديلات إلى مستودع GitHub الخاص بك
git push origin main
```
*(ملاحظة: إذا كان الفرع الافتراضي لديك اسمه `master` بدلاً من `main`، يرجى كتابة `master` في الأمر الأخير).*

---

## الخطوة 2: الاتصال بالسيرفر والدخول لمجلد المشروع
افتح الطرفية واتصل بسيرفر VPS الخاص بك ثم انتقل لمجلد المشروع:

```bash
# 1. الاتصال بالسيرفر عبر SSH
ssh root@5.35.87.221

# 2. الانتقال إلى مجلد المشروع
cd /var/www/video-courses
```

---

## 3. استيراد التحديثات الجديدة من GitHub إلى السيرفر
لتحديث ملفات المشروع على السيرفر بآخر نسخة قمت برفعها:

```bash
git pull origin main
```
*(ملاحظة: إذا كان فرعك هو `master` اكتب: `git pull origin master`).*

---

## الخطوة 4: تثبيت المكتبات الجديدة (Dependencies)
في حال قمت بإضافة أي مكتبات برمجية جديدة للمشروع أثناء التطوير:

```bash
pnpm install
```

---

## الخطوة 5: إعادة بناء المشروع (Build)
يجب إعادة بناء ملفات الواجهة الأمامية والواجهة الخلفية ليتم تطبيق التحديثات البرمجية:

```bash
# 1. بناء خادم الـ API (الخلفية)
pnpm --filter @workspace/api-server run build

# 2. بناء الواجهة الأمامية (React Frontend)
pnpm --filter @workspace/video-courses run build

# 3. تحديث جداول قاعدة البيانات (إذا أضفت أو عدلت على جداول قاعدة البيانات)
pnpm --filter @workspace/db run push
```

---

## الخطوة 6: إعادة تشغيل خادم الـ API عبر PM2
لجعل خادم Node.js يقرأ ملفات البناء الجديدة ويطبق التحديثات في الخلفية:

```bash
pm2 restart video-courses-api
```

---

## الخطوة 7: تحديث خادم ويب Nginx
إعادة تشغيل Nginx لتنظيف ذاكرة التخزين المؤقت وضمان استجابة الموقع السريعة:

```bash
sudo systemctl restart nginx
```

---

## 🔍 في حال حدوث أي مشكلة أو للتأكد من السلامة
إذا واجهتك أي مشكلة بعد التحديث، يمكنك فحص الأخطاء عبر الأوامر التالية:

* **لمشاهدة سجل تشغيل خادم الـ API الخلفي:**
  ```bash
  pm2 logs video-courses-api --lines 50
  ```
* **لفحص صحة ملف إعدادات Nginx:**
  ```bash
  sudo nginx -t
  ```
